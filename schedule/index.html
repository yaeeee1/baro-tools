칠할 유형

월간 근무표를 빠르게 완성하는 방법

직원별로 한 달을 전부 채우기보다 먼저 휴가·교육처럼 고정된 일정을 표시한 뒤, 날짜별 필요한 인원을 보며 기본 근무를 배정하세요. 휴무를 빈칸으로 두면 미배정과 혼동될 수 있으므로 ‘휴무’ 유형을 따로 만들어 표시하는 것이 좋습니다.

1. 유형 이름부터 통일

주간·야간·휴무처럼 짧고 의미가 겹치지 않는 이름을 사용하세요. 같은 이름인데 시간이 다르면 핵심 시간을 이름에 덧붙입니다.

2. 배포 전에 빈칸 확인

직원 누락, 월말 날짜, 의도하지 않은 빈칸을 확인하고 흑백 인쇄에서도 유형 이름으로 내용을 구분할 수 있는지 살펴보세요.

근무표 검토 체크리스트 →

3. 이미지와 백업을 함께 보관

직원에게는 최종 이미지를 공유하고, 작성자는 나중에 수정할 수 있도록 날짜가 포함된 백업 파일을 별도로 보관하는 편이 안전합니다.

쓰는 법 — 근무 유형과 직원을 등록하고, 위에서 칠할 유형을 고른 뒤 칸을 누르면 배정됩니다. 같은 칸을 다시 누르면 지워집니다. 드래그하면 여러 칸을 한 번에 칠할 수 있습니다.
백업 — 작업 내용은 이 브라우저에만 저장됩니다. 다른 기기에서 이어서 작업하거나 기록을 오래 남기려면 백업 파일을 받아두세요. 파일 이름은 제목과 보고 있는 달로 자동으로 정해집니다.
