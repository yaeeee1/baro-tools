브라우저 저장·백업·이미지 출력 안내

서버에 자료를 보내지 않는 대신 사용자가 보관을 책임져야 합니다. 자동 저장과 백업 파일의 차이를 이해하면 브라우저 데이터를 지우거나 기기를 바꿀 때 작업을 잃는 일을 줄일 수 있습니다.

작성: baro-tools 운영자최근 검토: 2026년 7월 27일읽는 시간 약 4분
목차자동 저장백업 파일복원이미지·인쇄개인정보자주 묻는 질문

자동 저장은 현재 브라우저에만 남습니다

도구에 입력한 내용은 사용 중인 브라우저의 로컬 저장공간에 자동으로 보관됩니다. 같은 기기와 같은 브라우저에서 다시 열면 이어서 작업할 수 있지만, 다른 컴퓨터나 다른 브라우저에는 자동으로 동기화되지 않습니다.

시크릿 모드, 브라우저 데이터 삭제, 기기 초기화, 저장공간 정리 기능을 사용하면 자동 저장 내용이 사라질 수 있습니다. 중요한 기록을 장기간 맡기는 저장소로 생각해서는 안 됩니다.

중요한 작업은 백업 파일로 한 번 더 보관

‘백업 파일 저장’ 버튼은 현재 작업 내용을 파일로 내려받습니다. 월별 근무표나 급여명세서처럼 나중에 수정할 가능성이 있는 자료는 완성 시점마다 백업하는 것이 좋습니다.

  • 파일 이름에 문서 종류와 대상 월이 들어갔는지 확인하기
  • 회사 문서 폴더처럼 접근 권한이 관리되는 위치에 보관하기
  • 개인정보가 포함된 파일을 공개 공유 폴더에 두지 않기
  • 수정 전과 최종본을 구분할 수 있게 파일 이름 정하기
예: 근무표 백업은 2026년 당직표 백업.json, 이미지는 2026년 8월 당직표.png처럼 제목과 대상 시점이 파일 이름에 자동으로 들어갑니다. 여러 번 백업할 때는 뒤에 날짜를 덧붙여 최종본을 구분하세요.

다른 기기에서 작업 이어가기

  1. 기존 기기에서 해당 도구를 열고 ‘백업 파일 저장’을 누릅니다.
  2. 내려받은 파일을 안전한 방법으로 새 기기로 옮깁니다.
  3. 새 기기에서 같은 도구를 열고 ‘백업 불러오기’를 선택합니다.
  4. 복원된 제목, 직원·과목 목록, 날짜와 금액이 맞는지 확인합니다.
  5. 확인이 끝날 때까지 기존 백업 파일을 삭제하지 않습니다.

근무표 백업은 근무표 도구에서, 시간표 백업은 시간표 도구에서 불러와야 합니다. 서로 다른 도구의 파일을 억지로 수정해 넣으면 복원되지 않거나 내용이 예상과 다르게 표시될 수 있습니다.

이미지는 공유용, 백업 파일은 수정용

형식적합한 용도주의사항
이미지메신저 공유, 빠른 확인내용을 다시 편집할 수 없고 개인정보가 그대로 보입니다.
인쇄/PDF게시, 문서 보관, 출력인쇄 미리보기에서 잘림과 방향을 확인합니다.
백업 파일나중에 수정, 다른 기기에서 복원일반 문서처럼 열기 위한 파일이 아니며 안전하게 보관해야 합니다.

최종 공유 전에 이미지의 가장자리, 문서 제목, 대상 월, 이름과 금액을 확인하세요. 특히 급여명세서는 다른 사람의 문서가 섞이지 않았는지 확인한 뒤 개별 전달해야 합니다.

로컬 처리도 개인정보 관리가 필요합니다

서버로 전송되지 않는다고 해서 정보가 자동으로 보호되는 것은 아닙니다. 공용 컴퓨터에 자동 저장을 남기거나, 개인정보가 포함된 이미지를 공개 링크로 공유하면 다른 사람이 볼 수 있습니다.

  • 공용 기기에서는 사용 후 작업을 지우고 내려받은 파일도 삭제합니다.
  • 급여 자료는 조직의 문서 보관 기준에 맞는 위치에 저장합니다.
  • 메일이나 메신저로 보낼 때 수신자를 다시 확인합니다.
  • 불필요해진 백업과 출력물은 안전하게 폐기합니다.
필요한 도구로 돌아가기

근무표·시간표·급여명세서 도구는 모두 백업과 이미지 출력을 지원합니다.

자주 묻는 질문

사이트 운영자가 제 입력 내용을 볼 수 있나요?

도구 입력값은 서버로 전송하지 않도록 설계되어 현재 브라우저 안에서 처리됩니다. 다만 외부 공유나 기기 보관은 사용자가 직접 관리해야 합니다.

백업 파일을 더블클릭하면 내용이 보이나요?

백업 파일은 해당 baro-tools 도구에서 불러오기 위한 데이터입니다. 내용을 확인하거나 수정하려면 원래 도구에서 ‘백업 불러오기’를 사용하세요.

자동 저장을 완전히 지우려면 어떻게 하나요?

각 도구의 ‘전체 지우기’를 사용하세요. 브라우저 전체 데이터를 지우면 다른 사이트의 로그인이나 설정도 함께 사라질 수 있으니 범위를 확인해야 합니다.
